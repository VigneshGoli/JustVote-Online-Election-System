# 🗳️ JustVote - Online Election System  

JustVote is a secure and efficient **online election system** designed to streamline the voting process while ensuring transparency and accessibility. This project aims to **digitize elections**, making them more secure, scalable, and easy to manage.  

---

##  Features  

✅ **Secure Authentication** – Ensures only registered users can vote  
✅ **Real-Time Vote Counting** – Displays live election results  
✅ **Role-Based Access Control** – Separate access for admins and voters  
✅ **User-Friendly Interface** – Simple and intuitive voting experience  
✅ **Fraud Prevention Mechanism** – Prevents duplicate and unauthorized voting
